⚠️ NVIDIA requer Proxy!

A API da NVIDIA bloqueia chamadas diretas do navegador (CORS).

Opcoes de Proxy:
1. Cloudflare Worker (gratis, 100k req/dia)
2. Vercel Edge (gratis, 1M req/mes)
3. Node.js local (localhost:3000)

Como usar:
- Deploy o proxy (arquivos fornecidos)
- Cole a URL do proxy abaixo
- Cole sua API Key da NVIDIA
Ex: https://nvidia-proxy.seunome.workers.dev (Cloudflare) ou http://localhost:3000 (local)
Obtenha em build.nvidia.com/settings/api-keys
